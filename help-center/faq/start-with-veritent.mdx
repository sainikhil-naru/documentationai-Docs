## Welcome

To start using Veritent for Okta IAM:

1. Sign up at `https://dashboard.veritent.com`
2. Verify your email address
3. Complete your profile info
4. Add your organization details
5. Connect your Okta org:
   - Enter Okta Org URL
   - Generate new Okta API token
   - Paste the token securely
