## Connect Okta SSO

<Steps>
  <Step title="Open Integrations">
    Go to Integrations section in Veritent dashboard.
  </Step>
  <Step title="Add Okta Organization">
    Click "Add Okta" and enter your Okta Org URL.
  </Step>
  <Step title="Generate API Token">
    Log into Okta as admin. Go to Admin > Security > API > Tokens. Click "Create Token." Copy token.
  </Step>
  <Step title="Paste into Veritent">
    Paste your Okta API token in Veritent and save.
  </Step>
  <Step title="Test Connection">
    Click "Test Connection". Success message confirms linked SSO.
  </Step>
</Steps>
